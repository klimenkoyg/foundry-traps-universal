# Что проверить в настоящей Foundry

Стенд (`dev/harness`) имитирует Foundry и «неизвестную» систему. В живом мире проверить:
одна d20-система без автоматизации (например, Shadowdark) и одна совсем другая (например, Simple
Worldbuilding) в режиме «Только ведущий».

- [ ] При первом входе ведущему открываются «Правила»; Настройки → «Правила ловушек» и кнопка ⚖ в
      библиотеке открывают то же окно; сохранение переживает перезагрузку.
- [ ] Пути к бонусу и КД из листа: «Проверить на выделенном токене» находит числа.
- [ ] Игрок кнопкой: бросок формулой мастера с бонусом; без пути — окошко «ваш бонус».
- [ ] Игрок вводит итог; ведущий отмечает «Успех / Провал»; атака без КД — «Попадание / Промах».
- [ ] Урон в полоску bar1 (и временные хиты, если система их умеет); по своему пути; «никуда».
- [ ] Состояния системы накладываются; несуществующее — словами в карточке.
- [ ] Обнаружение: пассивно по пути, тайная проверка один раз на ловушку; поиск — ответ ведущему.
- [ ] Обезвреживание: провал на N — срабатывает; режим ведущего — окошко с исходом.
- [ ] Экспорт и импорт правил в JSON.

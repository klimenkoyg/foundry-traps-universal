# Что нового в «Западне · Universal»

## 0.1.0

Первая версия для любой системы — отдельный модуль на основе «Западни» 0.2.7 для D&D 5e. Анимации,
звуки, окна, кнопки на карте и триггеры — те же; правила проверок и урона настраивает мастер.

- Окно «Правила»: пресеты «Обычный d20» и «Только ведущий», сохранение в файл и загрузка.
- Кто бросает спасброски: модуль сам, игрок кнопкой, игрок вводит свой итог, ведущий отмечает исход
  кнопками «Успех / Провал».
- Формула броска с `@bonus`, сравнение «не меньше» или «не больше цели», цель — Сл ловушки или число
  из листа персонажа, криты (нет / по кубику / ±10), урон вдвое при крите — по галочке.
- Свои спасброски и навыки с путями к числам в листе; категории каталога (увернуться, выдержать,
  устоять разумом, заметить, механизм, сила, магия) сопоставляются им. Проверка путей на
  выделенном токене.
- Урон — в полоску хитов токена, по своему пути или никуда; состояния — из системы, с ручным
  сопоставлением.
- Обнаружение: никак, пассивное число из листа или тайная проверка один раз на ловушку.
- Обезвреживание: «провал на N и больше — срабатывает»; в режиме ведущего — окошко с исходом.
- Атака ловушки без пути к КД — попадание отмечает ведущий.
- Можно ничего не настраивать: урон идёт в полоску хитов, бонус игрок вписывает сам. Окно «Правила»
  — простое: пресет, кто бросает, куда урон; остальное — в «Расширенных настройках».
- Модуль узнаёт систему мира и подставляет её правила: Shadowdark, OSE, DCC, Dragonbane, Black Flag,
  Level Up A5e, Starfinder 2e, Call of Cthulhu 7e, Daggerheart, Savage Worlds.
- «Найти в листе»: модуль сам ищет у выделенного персонажа спасброски, навыки, КД и хиты.
- Пути складываются через «+» и имеют запасной через «|»; у проверки может быть своя формула и
  сравнение.
- Состояния под другими именами модуль находит сам (blinded → blind, restrained → restrain / entangled).
